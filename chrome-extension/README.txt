ClipDrop Video Finder — Chrome extension v1.0.0

Install locally on Windows or macOS:
1. Extract the ZIP into a permanent folder.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Choose Load unpacked and select the folder containing manifest.json.
5. Pin ClipDrop from Chrome's Extensions menu.

Open a video page and click ClipDrop. Exposed video files can download
directly through Chrome. Choose formats opens the selected page/source
in the ClipDrop website; click Fetch video there to continue.

Some sites expose video files only after playback starts. Scan again then.
DRM, private access, browser-only blob streams, and cross-origin frame
contents are not captured. YouTube may block server-side extraction.
Download only content you own or have permission to save.

Privacy: scanning occurs only when you open the popup or click Scan again.
The extension has no persistent site access, analytics, account, cookie
reading, browsing-history storage, or background network interception.
Choosing ClipDrop sends the selected URL to the website. Direct downloads
use Chrome's download manager. The extension requests activeTab, scripting,
and downloads permissions. No payment is required.

This is an unpacked developer build, not a Chrome Web Store publication.
Chrome and website restrictions can prevent some sources from downloading.
