Netlify project: clipdrop-video-downloader
Site ID: ecb66257-cf2f-4635-86ea-a0ee90072194

The Netlify site hosts the page and an authenticated proxy. The Python
downloader is packaged separately in Dockerfile and render.yaml.

Backend setup:
1. Deploy this folder as a Docker web service on a Python/Docker host.
   render.yaml is an optional Render Blueprint (single instance).
2. Set BIND_HOST=0.0.0.0 and PORT to the host's required port.
3. Set API_TOKEN to a long randomly generated secret. Keep it private.
4. Set BACKEND_URL (HTTPS origin) and BACKEND_API_TOKEN (same secret)
   as Netlify Functions environment variables, then redeploy Netlify.
5. Verify /api/health and a complete merged download on the public site.

The Netlify page and API proxy are published and connected. Backend credentials
are stored in provider environment variables, not in these source files.
Keep one backend instance: job state is currently in memory. Files use
ephemeral disk and are lost on restart. Add quotas, expiry and durable
job storage before operating this as a high-volume public service.

SEO includes canonical URL, metadata, crawlable FAQs, WebSite structured
data, social previews, sitemap.xml, robots.txt and a noindex 404 page.
Google rankings and indexing are not guaranteed. Add a custom domain and
verify ownership in Google Search Console to submit sitemap.xml.

YouTube verification:
If YouTube requires sign-in or bot verification, browser sign-in on the
Netlify website cannot authenticate the Render server. The administrator
can optionally configure a Netscape-format YouTube cookie file as a Render
secret file and set YOUTUBE_COOKIE_FILE to its absolute runtime path.
Keep cookie contents out of chat, repositories, static assets and logs.
Use only a session you control and understand that yt-dlp warns account
use can risk suspension. A cookie session may expire or still be rejected.
The local app can work for videos blocked from a hosting-provider network.
