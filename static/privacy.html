Privacy notice

Updated 29 October 2026.

Website requests

When you submit a video URL, ClipDrop sends it to the extraction server to request media information and prepare the selected file. The source website receives requests from that server. Hosting providers, Netlify and Render, may process technical request logs such as IP addresses, URLs and timestamps.

Temporary processing

The server caches recent media metadata in memory for up to five minutes of reuse. Prepared downloads and job state are held on the server; files remain on temporary hosting storage until removed or the instance is replaced. A save link becomes unusable after one use or ten minutes. Link expiry is not a promise that the underlying file has already been deleted.

Chrome extension

The extension scans exposed video elements, media links, player metadata and supported iframe URLs only after you open it or choose Scan again. It does not request access to your full browsing history or browser cookies. Direct downloads use Chrome’s download manager. Choosing formats opens the selected URL in ClipDrop, where it is processed as described above.

Payments and advertising

The site does not collect payments or donation receipts. An AdSense ownership-verification tag is present; ad-serving code has not been enabled. Verification is not ad approval.

Your choice

Do not submit private video links, login credentials or sensitive personal information. Use the source provider’s official download controls when appropriate. You can remove the extension at any time through Chrome’s Extensions settings.
