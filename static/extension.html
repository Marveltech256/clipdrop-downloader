ClipDrop Video Finder for Chrome

A small extension that scans the page when you click it. Exposed video files can be downloaded directly. Embedded players and supported pages can be opened in ClipDrop to choose an available format.

Download extension ZIP

This is a developer build. It has not been submitted to or approved by the Chrome Web Store.

Install on Windows or macOS

  1. Download and extract the ZIP into a permanent folder.
  2. Type chrome://extensions into Chrome’s address bar.
  3. Enable Developer mode.
  4. Choose Load unpacked and select the extracted folder containing manifest.json.
  5. Pin ClipDrop from Chrome’s Extensions menu.

Use it on a video page

  1. Open a public video page. Start playback if no source is exposed yet.
  2. Click the ClipDrop extension icon.
  3. Choose Download file for an exposed file, or Choose formats to open the source in ClipDrop.
  4. For server extraction, click Fetch video on the website. A site may still restrict the server.

Permissions

activeTab lets the extension inspect the tab after your click. scripting runs the video-source scanner in that tab. downloads sends selected exposed files to Chrome’s download manager.

Limits

The extension does not decrypt DRM or capture hidden network streams. Browser-only blob URLs cannot be downloaded by this version. It cannot inspect the contents of cross-origin frames, although exposed supported-player URLs may be found. Chrome internal pages and some browser documents cannot be scanned.

Privacy

There is no background browsing-history collection, account, analytics or cookie-reading permission. Scanning is triggered by opening the popup or clicking Scan again. Direct file downloads stay in Chrome. Choosing ClipDrop sends the selected URL to the website, which may send it to its extraction server and the source site. Avoid submitting private or credential-bearing URLs.
